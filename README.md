## Das Problem

Ein Shop im EU-Raum muss Verbraucherinnen und Verbrauchern den Widerruf **elektronisch** ermöglichen — nicht nur im Text erklären, sondern als benutzbares Formular anbieten. In der Praxis endet das oft bei einer E-Mail-Adresse in der Widerrufsbelehrung, und jeder eingehende Widerruf wird von Hand in eine Tabelle übertragen.

Dazu kommt der mobile Bestellabschluss: Auf dem Handy scrollt der Kaufknopf aus dem Bild, sobald jemand die Bestellübersicht prüft. Genau in diesem Moment bricht die Bestellung ab.

## Die Lösung

Pro ergänzt **drei** Bausteine. Die Liste ist vollständig — alles andere steckt bereits in der kostenlosen Version und bleibt dort.

## Features

- 📝 **Online-Widerrufsformular** — automatisch angelegte Formularseite für Gäste **und** eingeloggte Kundschaft, „Bestellung widerrufen" im Kundenkonto, weiche Bestell-Zuordnung, die eine Einsendung nie blockiert, Händler-Benachrichtigung und Eingangsbestätigung per E-Mail
- 🗂️ **Verwaltung unter WooCommerce → Widerrufe** — Tabelle mit Status-Workflow statt Postfach-Archäologie
- 📱 **Mobile Sticky-Bestellleiste** — Gesamtsumme und Kaufknopf bleiben sichtbar, solange der echte Knopf außer Sicht ist
- 📐 **Ultra-kompaktes Layout** — der Dreispalter, dichter gesetzt: alles auf einen Blick, ohne zu scrollen
- 🔑 **Lizenz und Updates im WordPress-Backend** — Schlüssel eintragen unter WooCommerce → Lizenz, neue Versionen erscheinen wie bei jedem anderen Plugin
- 🧩 **Saubere Erweiterungspunkte** — Pro hängt sich ausschließlich in dokumentierte Filter der freien Version, forkt nichts und ändert keine ihrer Dateien

## Die Lizenz sperrt keine Funktion

Sie steuert **Updates und Support** — mehr nicht. Läuft sie aus, arbeitet das Plugin unverändert weiter; es kommen lediglich keine Aktualisierungen mehr an, und das Backend sagt Ihnen das.

Der Grund ist nicht Großzügigkeit, sondern Haftung: Das Widerrufsformular ist eine **gesetzliche Pflicht**. Liefe es mit der Lizenz ab, würde Ihr Shop im selben Moment rechtswidrig. Eine Bezahlschranke, die den Kunden ins Risiko stellt, ist keine Option.

Eine Lizenz bindet an eine Produktivdomain; Staging- und lokale Hosts (`staging.`, `dev.`, `.local` und ähnliche) verbrauchen diese Bindung nicht.

## Installation

1. Kostenlose Basis installieren und aktivieren — ohne sie bleibt Pro still
2. Pro-ZIP aus **Mein Konto → Downloads** laden
3. **Plugins → Installieren → Plugin hochladen**, aktivieren
4. Lizenzschlüssel unter **WooCommerce → Lizenz** eintragen
5. Die Pro-Einstellungen erscheinen in derselben Oberfläche wie die der Basis: **WooCommerce → Smart Checkout**, Reiter **Recht** und **Kasse**

Für Composer-verwaltete Installationen (z. B. Bedrock) liegt das Paket zusätzlich im STM-Repository bereit; die Zugangsdaten kommen nach dem Kauf per E-Mail.
